排序算法总结

本讲义总结了常见的六大内部排序算法，通过交互式动画直观地展示它们的核心思想、性能特点与局限。

插入排序

通过维护一个“已排序区间”，不断将未排序区间的元素插入到适当位置。逻辑类似于整理扑克牌。

平均时间： O(n²)

最坏时间： O(n²)

最好时间： O(n)

空间复杂度： O(1)

稳定性： ✔ 稳定

动画演示：插入排序

参考代码 (C)

void InsertRange(int a[], int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        int end = i;
        int temp = a[end + 1];

        // 动画：temp 为 'current'，a[end] 为 'compare'
        while (end >= 0 && a[end] > temp)
        {
            a[end + 1] = a[end]; // 动画：元素右移
            end--;
        }

        a[end + 1] = temp; // 动画：插入元素
    }
}

希尔排序

基于插入排序，通过“分组+缩小 gap”方式加速排序效率。

平均时间： O(n^1.3)

最坏时间： O(n²)

最好时间： O(n)

空间复杂度： O(1)

稳定性： ✘ 不稳定

动画演示：希尔排序

观察不同 `gap` 下的“分组插入排序”。

参考代码 (C)

void ShellSort(int a[], int n)
{
    // 动画：gap 会不断变化
    for (int gap = n / 2; gap > 0; gap /= 2)
    {
        for (int i = gap; i < n; i++)
        {
            int temp = a[i];
            int end = i - gap;

            // 动画：同组元素(a[i], a[end])进行比较
            while (end >= 0 && a[end] > temp)
            {
                a[end + gap] = a[end];
                end -= gap;
            }
            a[end + gap] = temp;
        }
    }
}

堆排序

基于大顶堆 / 小顶堆 实现的选择型排序。每次把堆顶（最大值）放到末尾。

平均时间： O(n log n)

最坏时间： O(n log n)

最好时间： O(n log n)

空间复杂度： O(1)

稳定性： ✘ 不稳定

动画演示：堆排序

先观察“建堆”（向下调整），再观察“排序”（交换堆顶与末尾）。

参考代码 (C)

void AdjustDown(int a[], int size, int root)
{
    int parent = root;
    int child = 2 * parent + 1; // 动画：比较 parent 和 child
    while (child < size)
    {
        if (child + 1 < size && a[child] < a[child + 1])
            child++; // 选出较大的孩子

        if (a[child] > a[parent])
        {
            Swap(a + child, a + parent); // 动画：交换
            parent = child;
            child = parent * 2 + 1;
        }
        else break;
    }
}
void HeapSort(int a[], int size)
{
    // 1. 建堆
    for (int i = (size - 2) / 2; i >= 0; i--)
        AdjustDown(a, size, i);

    // 2. 排序（交换堆顶和末尾）
    int end = size - 1;
    while (end > 0)
    {
        Swap(&a[0], &a[end]); // 动画：交换，a[end] 变为 'sorted'
        AdjustDown(a, end, 0); // 动画：重新调整堆
        end--;
    }
}

选择排序

每次从未排序区间选择最小（或最大）元素放到正确位置。（讲义中是优化版，同时找最小和最大）。

平均时间： O(n²)

最坏时间： O(n²)

最好时间： O(n²)

空间复杂度： O(1)

稳定性： ✘ 不稳定

动画演示：选择排序（优化版）

观察 `mini` 和 `maxi` 指针如何在未排序区间移动。

参考代码 (C)

void SelectSort(int a[], int size)
{
    int begin = 0, end = size - 1;
    while (begin < end)
    {
        int mini = begin, maxi = begin;
        // 动画：i 遍历，mini 和 maxi 跟踪 min/max
        for (int i = begin; i <= end; i++)
        {
            if (a[i] < a[mini]) mini = i;
            if (a[i] > a[maxi]) maxi = i;
        }

        Swap(a + begin, a + mini); // 动画：交换 mini 到 begin
        
        // 关键：如果 maxi 在 begin 处，它刚被换走了
        if (begin == maxi)
            maxi = mini;

        Swap(a + end, a + maxi); // 动画：交换 maxi 到 end
        begin++;
        end--;
    }
}

快速排序

通过选取基准元素（Pivot），把数组划分为左右两个区间并递归处理。（演示为挖坑法）。

平均时间： O(n log n)

最坏时间： O(n²)

最好时间： O(n log n)

空间复杂度： O(log n)

稳定性： ✘ 不稳定

动画演示：快速排序（挖坑法）

观察 `pivot`（坑）的位置如何移动，以及 `begin` 和 `end` 指针的相遇。

参考代码 (C)

int PartSort1(int a[], int left, int right)
{
    int begin = left, end = right;
    int pivot = begin; // 动画：pivot 为 'pivot' 状态
    int key = a[pivot];

    while (begin < end)
    {
        // 动画：end 指针 ('compare') 向左找小
        while (begin < end && a[end] >= key) end--;
        a[pivot] = a[end]; // 动画：填坑，pivot 移到 end
        pivot = end;

        // 动画：begin 指针 ('compare') 向右找大
        while (begin < end && a[begin] <= key) begin++;
        a[pivot] = a[begin]; // 动画：填坑，pivot 移到 begin
        pivot = begin;
    }

    a[pivot] = key; // 动画：key 归位
    return pivot;
}

归并排序

通过“分治 + 合并”实现稳定、高效的排序。

平均时间： O(n log n)

最坏时间： O(n log n)

最好时间： O(n log n)

空间复杂度： O(n)

稳定性： ✔ 稳定

动画演示：归并排序

观察递归“分解”到底层，然后“合并”两个有序子数组的过程。

参考代码 (C)

void _MergeSort(int a[], int left, int right, int *temp)
{
    if (left >= right) return;
    int mid = (left + right) >> 1;

    _MergeSort(a, left, mid, temp);
    _MergeSort(a, mid + 1, right, temp);

    int begin1 = left, end1 = mid;
    int begin2 = mid + 1, end2 = right;
    int index = left;

    // 动画：比较 begin1 和 begin2
    while (begin1 <= end1 && begin2 <= end2)
    {
        if (a[begin1] <= a[begin2])
            temp[index++] = a[begin1++];
        else
            temp[index++] = a[begin2++];
    }
    while (begin1 <= end1) temp[index++] = a[begin1++];
    while (begin2 <= end2) temp[index++] = a[begin2++];

    // 动画：将 temp 拷回 a (合并完成)
    for (int i = left; i <= right; i++)
        a[i] = temp[i];
}
